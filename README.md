# CurveX Lab 📐

**CurveX Lab** · Pick where it starts, pick where it graduates.
A decentralized launchpad on **Raydium LaunchLab** where every coin gets its own customizable bonding curve.

## Overview
- **Custom Start & Graduation Cap**: Creators can set their starting market cap and graduation cap.
- **Built on Raydium LaunchLab**: Native Solana execution, non-custodial wallet signatures.
- **Real-time DEX Tracking**: Live curve multipliers, liquidity progress, and Raydium graduation routing.
